# Mike Command Center

A private, mobile-first personal dashboard built around:
- Trading journal and setup review
- 15-minute market-structure checklist
- Daily operating routine
- Goals
- Spending tracker
- NOCTRA idea vault

## Fastest way to use it on iPhone
1. Open `index.html` in Safari or Files.
2. In Safari, use Share -> Add to Home Screen.
3. The data is stored locally on the device/browser using localStorage.

For a true App Store / native app, the same UI can be moved into an Expo/React Native project later.
